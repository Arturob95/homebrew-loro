# Loro para Homebrew / Loro for Homebrew

Dictado por voz y notas de reuniones con IA, para Mac, en español y en inglés. / AI voice dictation and meeting notes for Mac, in English and Spanish.

```
brew install --cask arturob95/loro/loro
```
